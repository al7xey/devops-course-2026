# Мой пет-проект

Идея: телеграм-бот для учёта личных расходов. Пишешь боту "кофе 250" - он сохраняет трату с категорией, а по команде /stats присылает сводку за неделю или месяц.
Стек: Python (aiogram), SQLite, позже Docker
Цель: научиться упаковывать приложение в контейнер и настроить автодеплой на сервер через GitHub Actions

## Сроки
- сентябрь: бот принимает траты и сохраняет их в SQLite
- октябрь: команда /stats и категории
- ноябрь: Dockerfile и деплой через GitHub Actions
