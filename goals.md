# Цели на семестр

1. Разобраться с Docker на практике: собрать образ для своего проекта и поднять его через docker-compose.
2. Настроить CI/CD на GitHub Actions, чтобы при пуше в main автоматически запускались тесты и сборка.
3. Уверенно работать в Linux через терминал: bash-скрипты, systemd, права доступа, базовые сетевые утилиты.
