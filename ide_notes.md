# Git в VS Code и в терминале

Что удобно в VS Code:
1. Diff открывается сразу рядом с файлом, видно построчно что поменялось, не надо гонять git diff.
2. Можно добавить в индекс не весь файл, а отдельные строки (Stage Selected Ranges).
3. GitLens показывает автора и коммит прямо на строке, плюс удобная история файла.

Что удобнее в терминале:
- rebase, reset, cherry-pick и вообще всё, что сложнее commit/push. В UI эти вещи либо спрятаны, либо непонятно что именно выполнится. В терминале видно точную команду и её вывод.
